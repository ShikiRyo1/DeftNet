# v0.1.0 Code Release

This is the first public DeftNet / DEFT-Net research-code release.

## Scope

- cleaned PyTorch package under `src/deftnet`;
- train, evaluate, and inference entry points;
- audited and legacy YAML configs;
- aggregate DCA fixed-threshold/no-TTA result table;
- reproducibility, data, model-card, and artifact-roadmap documentation;
- per-image metric, paired statistics, split-manifest, profiling, and gallery
  utility scripts;
- synthetic API demo and CPU smoke tests.

## Not Included

- raw datasets or clinical images;
- final trained checkpoints;
- final paper DOI/arXiv citation;
- final per-image prediction masks or split manifest.

Those artifacts require final manuscript, licensing, and privacy decisions before
public release.
